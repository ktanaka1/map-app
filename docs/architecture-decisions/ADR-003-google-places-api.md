# ADR-003: 外部APIにGoogle Places APIを採用

## 状況
飲食店の検索・クチコミ表示に外部APIが必要。

## 選択肢
- Google Places API: 世界規模、クチコミ豊富、従量課金（月$200無料枠）
- ホットペッパーグルメAPI: 国内特化、無料、クチコミなし
- 両方併用: 各APIの強みを活用、実装が複雑

## 決定
Google Places API

## 理由
MVP要件の「クチコミ表示」「場所×キーワード検索」「GPS周辺検索」を全てワンストップでカバーできる。外部予約リンクもGoogle Maps経由で取得可能。従量課金だが月$200の無料枠がありMVP段階では十分。
