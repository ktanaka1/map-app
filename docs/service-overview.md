# サービス概要

## サービス名
（仮）map-app

## 何を作るのか
飲食店の予約とクチコミを管理するプラットフォーム。場所×キーワードで候補店を検索し、グループ全員がリアルタイムで投票してお店を1つに決める。

## ターゲットユーザー
飲食店を探す一般ユーザー（個人・グループ）。特に「その場にいる複数人で一緒にお店を決めたい」シーン。

## 大切にしたいこと
- **速さ**：ふと思い立ったときにすぐ検索結果が表示されること
- **精度**：キーワード×場所で的確な候補が出ること
- **クチコミの信頼性**：外部APIの実績あるクチコミを活用し、情報の質を担保すること

## ビジョン（最終目標）
複数人が外出先で各自のスマホを同期させ、画面を見ながら「いい」「よくない」を言い合い、全員の投票で最終的に1店舗に決まる——そんな体験のデファクトアプリになる。

## 主要ユーザーフロー

```
1. セッション開始（1人でも可）
   ├── [その場に全員集合] QRコードで参加 → 参加者確定
   └── [事前・遠隔]     リンクシェアで参加 → 参加者確定

2. キーワード入力フェーズ
   └── 参加者全員がキーワードを出し合う（追加・削除可能）

3. 検索
   └── 場所 × 全員のキーワードで飲食店を検索

4. 投票フェーズ
   └── 候補店を順に表示 → 各自がボタン（キープ／除外）で判定

5. 結果判定
   └── 全員の投票が揃ったら結果を表示 → 外部予約ページへ誘導
```

## MVP（最低限必要な機能）
1. **セッション参加**：QRコード（その場集合）＋リンクシェア（事前・遠隔）の両対応。1人参加も可能
2. **協調キーワード入力**：参加者全員がキーワードを出し合い、取捨選択できる
3. **場所×キーワード検索**：現在地やエリア＋収集したキーワードで飲食店を検索
4. **ボタンUI（キープ／除外）**：候補店に対して右ボタン（キープ）・左ボタン（除外）で絞り込む（スワイプ不要）
5. **リアルタイム同期投票**：複数人のスマホを同期し、全員の投票が揃った時点で結果を判定
6. **外部予約リンク**：決定したお店の外部予約ページ（食べログ・ぐるなび等）へ誘導
7. **クチコミ表示**：Google Places API等の外部APIからクチコミ・評価を取得して表示

## 仕様詳細（壁打ちで確定）

- **投票判定**: 全員一致でキープのみ通過。1人でもNGなら除外
- **全滅フォールバック**: 全候補が除外された場合、キープ数最多の店を提示
- **場所指定**: GPS現在地（デフォルト）＋テキスト手動入力の両対応
- **外部API**: Google Places API（飲食店検索・クチコミ・GPS周辺検索）
- **セッション管理**: タイムアウトあり。参加者が1人でも離脱したらセッション終了
